# AI usage and data rules (DRAFT, to be agreed with HSI)

1. Candidate personal data (resumes, contact details, career history) is not pasted into public AI tools.
2. Use approved tools only: local Ollama assistant for anything involving candidate data.
3. AI output is a draft. A named person reviews anything sent externally or about a person.
4. Facts, fees, policies and statistics come from verified HSI documents, with a source.
5. Career breaks are never treated as a negative signal in AI-assisted screening.
6. Candidate consent is required before sharing their profile with an employer.
7. Each knowledge-base document has an owner and a review date.
